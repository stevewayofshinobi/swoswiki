# Steve: Way of Shinobi — Wiki

Упрощённая русская версия вики для GitHub Pages.

## Структура

- `index.html` — главная страница
- `getting-started.html` — Начало игры
- `entities.html` — Существа
- `items.html` — Предметы
- `clans.html` — Кланы
- `jutsu.html` — Техники
- `404.html` — страница ошибки
- `assets/css/style.css` — весь внешний вид сайта

На сайте специально нет изображений и иконок. Их можно добавить позже.

## Публикация на GitHub Pages

1. Загрузите содержимое этой папки в корень репозитория.
2. Откройте `Settings → Pages`.
3. В `Source` выберите `Deploy from a branch`.
4. Выберите `main` и `/ (root)`.
5. Нажмите `Save`.

## Редактирование

Текст можно менять прямо внутри HTML-файлов.
Основные цвета и оформление находятся в `assets/css/style.css`.

Для заголовков используется подключаемый через Google Fonts пиксельный шрифт `Pixelify Sans`, поэтому никаких файлов шрифтов в репозитории не требуется.
